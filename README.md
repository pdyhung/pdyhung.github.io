# pdyhung.github.io

Trang cá nhân của Phạm Văn Hưng – Kỹ sư kết cấu thép.

- `index.html` – nội dung trang (song ngữ: phần tử `.vi` / `.en`)
- `css/style.css` – giao diện, chế độ sáng/tối
- `js/main.js` – đổi ngôn ngữ, giao diện, menu, lọc sách, xem ảnh
- `assets/` – hình ảnh, logo

Xem trên máy: mở `index.html` bằng trình duyệt.
