Các ký hiệu xây dựng và toán học thông dụng: bấm để sao chép vào bản vẽ, thuyết minh hay bảng tính. Mỗi ký hiệu kèm ý nghĩa và cách gõ trong AutoCAD, Excel, Word. Common construction and math symbols: click to copy into drawings, reports or spreadsheets. Each symbol comes with its meaning and how to type it in AutoCAD, Excel and Word.

Cách gõ ký hiệu bằng mãTyping symbols by code
  • AutoCAD (Text/MText): %%c = Ø, %%d = °, %%p = ±; ký hiệu khác gõany other symbol: \U+00B2 (= ²). Font phải có ký tự đó (Arial, Times New Roman…; font .shx như romans có thể thiếu).The font must contain the glyph (Arial, Times New Roman…; .shx fonts such as romans may lack it).
  • Excel: =UNICHAR(178) = ², hoặcor Insert → Symbol. Ghép chuỗi:Join text: ="Ø"&A1
  • Word: gõ mã hex rồi bấmtype the hex code then press Alt+X (VDe.g. 2264 → ≤). Chỉ số trên/dưới:Super/subscript: Ctrl+Shift+= / Ctrl+=.
  • Windows Alt: giữhold Alt và gõ mã trên bàn phím sốand type the code on the numeric keypad (VDe.g. Alt+0176 = °). Chỉ có với một số ký hiệu (hiện trên thẻ).Only some symbols have one (shown on the card).
  • Lưu ý: Ø (U+00D8, chữ O gạch) thường dùng thay ⌀ (U+2300, ký hiệu đường kính chuẩn) vì có trong hầu hết font.Note: Ø (U+00D8, slashed O) is commonly used instead of ⌀ (U+2300, the true diameter sign) because nearly every font has it.
